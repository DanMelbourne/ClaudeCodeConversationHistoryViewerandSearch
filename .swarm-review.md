You are reviewing Swift source for Claude Code Companion, a native macOS SwiftUI app
for browsing, searching, and managing Claude Code conversation history and CLAUDE.md files.
Built with SwiftUI (macOS 14+), SQLite FTS5, no external dependencies (except Sentry).

Hunt these classes of bug first — they're recurring in this codebase:

1. INVARIANT VIOLATIONS — feature verb implies a property not enforced:
   - "Expand"/"grow"      -> result >= original
   - "Bring into view"    -> active frame within viewport
   - "Reversible"         -> decode(encode(x)) == x
   - "Idempotent"         -> no change when precondition already holds
2. CONCURRENCY — MainActor violations, unstructured Task leaks, dangling continuations.
   All UI state lives in `@Observable AppViewModel` on MainActor. Heavy file I/O must
   run via `Task.detached` with results assigned back on MainActor. Static nonisolated
   helpers used for background parsing must not capture `self`.
3. MAIN-THREAD BLOCKING — synchronous file I/O called from @MainActor methods. Any
   method that reads file contents, enumerates directories, or counts lines must dispatch
   to a background task. `String(contentsOf:)` on the main thread is always a bug.
4. SQLITE — any string interpolation in SQL queries is a bug. Must use parameter binding.
   FTS5 queries must be sanitised (terms wrapped in quotes). Transactions must be
   committed or rolled back in all paths.
5. JSONL PARSING — streaming reads via FileHandle in 256KB chunks. Incomplete lines
   carried as leftover. Files can be multi-MB; loading entire file as String is a bug.
6. MEMORY — large JSONL files must not be loaded into a single String. Use streaming
   chunk-based reading. LazyVStack for conversation rendering. Avoid retaining rawJSON
   strings longer than needed.
7. SEARCH NAVIGATION — search results must resolve to the correct session file, including
   subagent files. `navigateToSearchResult` must find the actual JSONL file, not just the
   parent session. Scroll-to-message must wait for view mount before setting scrollToMessageId.
8. WORKTREE MERGING — folders with `--claude-worktrees-` suffix must merge with their
   parent project. Session counts and dates must aggregate across base + worktrees.
   `Project.allPaths` must include base path + all worktree paths.
9. EXTERNAL SOURCES — graceful handling when source directory is inaccessible (Mac offline).
   No error popups for missing network paths. Status indicators must reflect actual
   accessibility and staleness (>24h = stale).
10. SECURITY — no secrets in UserDefaults or logs, no hardcoded absolute paths in generated
    code, DSN via Info.plist not source code.
